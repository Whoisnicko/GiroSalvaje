# Asset Recovery — v22-alpha.7.22
User reported invisible guardians/humans and blank card art while the field and health bars remained visible. The original 384×384 character atlas in the local source snapshot contains all 16 characters. Production browser root cause could not be reproduced or inspected; the shared dynamic canvas-to-canvas conversion path was a plausible failure point. This hotfix replaces runtime cropping/recoloring/serialization with pre-baked PNG frames and static card/portrait data, produced from the existing approved artwork by the 7.21 renderer offline. 323 unique frames in six PNG sheets preserve idle/walk/attack, rank, flash and grayscale variants. Runtime draws directly from decoded images. If a sheet fails, use original atlas cells; if that also fails, draw a visible colored placeholder. Card/symbol art is independent of sprite sheets. Bounded loading timeout; new asset and script paths. No HUD layout, game rules, save schema, or Academy changes. New sheets add approximately 1.2 MB of downloads plus 299 KB portrait/card manifest before HTTP compression. Legacy 7.21 source remains in Git history for regeneration.
Validation: local Chromium, original assets inlined, simulated storage, simulated no-op canvas-to-canvas drawing; checked pixel content of every frame, cards/portraits, decoded image pixels, screenshot, original atlas fallback and missing atlas fallback. Academy and responsive regression suites passed. Production not verified; test actual browser after deployment. Next remains Infernal Codex after user confirms recovery.
