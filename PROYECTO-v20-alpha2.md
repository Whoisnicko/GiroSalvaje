# Stop Humans! v20-alpha.2

Tactical HUD: real incoming wave composition in bronze header above the canvas; remaining enemy counts during combat; expandable details. Live illustrated unit dossier for allied, reserve, temporary and enemy units. Hover or click to pin; close by click, X or Escape; hide during drag, card aiming or modal. HP, attack, interval, reach, movement, armor, special stats and buffs; allied armor is 0 because there is no allied armor mechanic. No new sprites, balance, shop or save schema changes. Syntax and isolated model/selection tests passed; browser QA pending.
