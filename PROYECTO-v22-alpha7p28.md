# Sandbox Encounter Director — v22-alpha.7.28

User requested direct access to any map, wave and boss without campaign progression. Free Sandbox panel opens automatically after relic selection. Map and boss selectors use the existing registries. Load wave / Play wave now; Load boss only / Fight boss now; Retry encounter. Boss selection automatically uses its native map and wave, with only that boss queued. Classic Commander is available on Valley wave 10. Switching during battle resets transient combat state, preserves army, reserve, relic, artifacts and God mode, heals and refills cards. Retry reuses the selected encounter's original queue, not later manual additions. Guided Academy and campaign remain separate; no progression unlock, rewards, score, or save schema changes. No new biomes or assets. Isolated encounter construction tests and JS syntax passed; live browser and production deployment pending.
