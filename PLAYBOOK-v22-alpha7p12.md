# Playbook — Valley Guide v22-alpha.7.12

Production: https://stophumans.pages.dev/
GitHub: https://github.com/Whoisnicko/StopHumans
Branch: main

1. Hard refresh and verify version. Open Guide in an existing run or start a new run after exporting your save. Completed/skipped guide state is preserved; Guide can restart manually.
2. Confirm darkened background, red pulsing target, arrow and non-overlapping instructions; click the real lever and HOLD. Try Minimize, Expand, Skip step and Skip guide. Check reduced-motion setting.
3. Move, stack/merge matching guardians and drag into/out of reserve. If a pair is unavailable, continue without forcing RNG. Confirm the actual successful action advances the guide.
4. Start battle, play a card, target an AIM card, use Q with each class. Sorcerer: draw the triangle, release, choose target. Warlord: choose landing point, move. Battle shade is intentionally lighter.
5. Survive a wave, open Hades Room and finish. Check guide hides on dialogs and menu. Test natural full wave, reload, different viewport sizes and mobile. Local testing used simulated storage and controlled state; verify production independently.
