# Stop Humans! v22-alpha.7.11 — The Valley Guide

Optional, contextual first-campaign tutorial in English, matching the existing game UI. Twelve data-driven lessons: altar, gacha, hold, formation/merge, reserve, return, DEFEND, cards, class ability, survive, Hades, finish. The Sorcerer teaches the starter Infernal Fire triangle, real rune recognition and mana; Warlord teaches real Q deployment, WASD/arrows and skill shortcuts. The spotlight is noninteractive; it does not block game controls or resize the battlefield. Skip each step or entire guide; the Guide footer button reopens it in a normal active run. Guide state is separate from the campaign save (gs22.tutorial.v1), scoped to a run ID; existing saves are not automatically enrolled. Sandbox excluded. Existing tips remain when guide is inactive. No RNG, combat, costs, rewards, save format or assets changed. If a wave is won early the guide moves to the Hades lesson; if lost it hides. The guide is not a separate scripted practice arena.

Validation: JS syntax checks; actual Chromium engine with original available atlas and battlefield, embedded local sources and simulated storage due to browser network restrictions. Sorcerer at 1852x757: first run, lever, hold, real pointer drag to/from reserve, actual card use, real triangle recognition and target, controlled wave transition, Hades open/close, completion, simulated restore, replay and skip. Warlord at 1852x757 and 1366x768: actual deployment and automatic lesson progression. No JS errors during completed scenarios. Natural full wave victory, real origin storage, mobile layout and Cloudflare deployment remain unverified. Some secondary art uses fallbacks in local test.
