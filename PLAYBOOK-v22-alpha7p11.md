1. Hard refresh; verify v22-alpha.7.11 in menu. Export an existing save before starting a new campaign. Existing runs: use Guide to test without replacing the save.
2. New campaign: choose class and relic. Guide appears for an untrained browser. Follow lever, hold, drag, reserve, return and DEFEND. Try Skip step and Skip guide. Confirm normal RNG and no input locks.
3. In combat, use a card and aim if needed. Sorcerer: Q, closed triangle in one stroke, then target. Warlord: Q then click a landing point, move and use skills.
4. Survive a wave; enter Hades; close it, finish guide. Reload and Continue: check progress restoration or completion. Guide button reopens manually. Check menu, Bestiary, Grimoire, and sandbox (guide disabled there).
5. Verify mobile/desktop layout and a full natural wave. Local validation used simulated storage and a controlled wave transition; deployment and real persistence not yet verified.
